# Anauê Design Project

## OpenCode CLI Installation

The OpenCode command‑line interface has been installed globally via npm:

```powershell
npm install -g @opencode/cli@latest
opencode --version   # v2.3.2
```

You can now run `opencode` from any terminal (including Antigravity’s integrated terminal). The first run will prompt you to configure a model provider and API key.
